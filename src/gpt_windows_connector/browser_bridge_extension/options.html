Local browser access settings

Connection

Lucas Node must be running on this computer. Profile names help select a browser; they do not restrict an AI to one Profile.

Website access

Blocked websites always take priority. Enter one hostname per line, such as example.com or *.example.com.

Developer access lets AI inspect and change page internals, execute page JavaScript, and inspect console/network data. Normal screenshots and protocol clicks do not require this setting.

Optional browser data

History access requires your approval for each lookup. Bookmarks access can be turned off at any time.
